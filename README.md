# LegacyLens V3

LegacyLens is a Digital Legacy Operating System designed to help individuals preserve, understand, organize, and share their digital legacy.

## Mission

LegacyLens exists to help people transform collections of digital files into meaningful archives containing people, relationships, events, timelines, and stories.

Files are not the goal.

Understanding is the goal.

## Current Capabilities

### Photos

- Archive Analysis
- Metadata Extraction
- Archive Health
- Exact Duplicate Detection
